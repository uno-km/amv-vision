# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or boundary breach within `termux-vision`, please report it privately:

1. **Email**: `dev@amevafoundation.org` or `zhfldk014745@naver.com`
2. **Security Advisories**: You may also open a private draft advisory via GitHub Security Advisories.

Please do not report security vulnerabilities through public GitHub issues. All security reports will receive a response within 48 hours.
